# An inspectable reduced analogy, not a deployed self-improving firm {#sec:conclusion}

AlphaFund's historical whitepaper motivates a corporate recursive-self-improvement
analogy [@westenhaver2026rsi]. AlphaCOGANT makes a bounded part of that analogy
executable: five capability factors, fixed likelihood/transition matrices,
one-step preference/information action scoring, and a separately evaluated
paired create-minus-decay statistic [@friston2010freeenergy; @friston2015epistemic;
@dacosta2020synthesis]. It does not establish equivalence between a continuous
financial objective and negative EFE.

The GNN model and NumPy engine preserve numerical coefficients and explicit axes;
complete joint export is exercised against pinned COGANT
[@friedman2026gnn; @friedman2026cogant]. Local filtering retains a product
approximation, while the external joint runtime uses a different inference and
objective contract. Interchange is not policy equivalence.

The useful outcome is inspectability: reviewers can trace an action to its model,
input observations and score decomposition, and regenerate numeric and visual
artifacts. Chronological data provenance, scientific interpretation, and freshness
of published bytes still require independent checks. Token coverage and current
file hashes cannot make arbitrary prose true.

## Research progress requires new behavioral and empirical evidence

A sustainability-constrained learning firm remains a substantive research question
[@coase1937; @milgrom1990]. The present model supplies a reproducible experimental
object, not a deployed financial test or self-modifying controller. Its limitations
include fixed coefficients, no solvency/capital state, discrete actions, inert
R&D-to-outcome coupling, approximate filtering and myopic planning
[@kaelbling1998pomdp; @friston2017process]. These boundaries should guide future
experiments, not be hidden by a general exploration/learning narrative
[@sutton2019bitter; @lattimore2020bandits].

No positive performance conclusion follows from increasing representation size,
bootstrap count, or model complexity. Progress would require specified data,
calibration, comparison objectives and new behavioral evidence. The current
contribution is an auditable reduced demonstration, not financial advice.
